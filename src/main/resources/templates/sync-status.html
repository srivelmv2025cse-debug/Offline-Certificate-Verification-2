Offline Verification Workflow

How verification succeeds when completely disconnected from the Internet:

1. Online Ledger

Institution issues certs & records blocks on SQLite blockchain.

→

2. Sync Snapshot

Package exported to JSON file with blocks, certs & public keys.

→

3. Offline Verifier

Verifier loads snapshot. Recalculates hash & verifies RSA signature.

→

4. Result

Genuine, Tampered, Revoked, Expired, or Not Found.
