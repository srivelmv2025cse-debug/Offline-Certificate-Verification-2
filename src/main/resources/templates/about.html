About This Project

A college project exploring blockchain-based certificate verification.

Project Objective

This project demonstrates how blockchain technology can be applied to issue and verify academic and professional certificates in a tamper-proof manner, with the unique ability to perform verification entirely offline.

Technologies Used

  • Java 21 — Core programming language
  • Spring Boot 3 — Backend web framework
  • SQLite — Lightweight embedded database
  • HTML / CSS / JavaScript — Frontend
  • ZXing — QR code generation and scanning
  • RSA Digital Signatures — Certificate authenticity
  • SHA-256 Hashing — Blockchain integrity
  • Maven — Build and dependency management

Current Status

Day 1: Project structure, database configuration, package layout, and homepage are complete. Core blockchain, QR, and verification features will be implemented in subsequent days.
